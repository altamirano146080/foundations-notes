\chapter{Sistemas de recomendación}
\section{Apuntes del Tema 13: Sistemas de recomendación}

\subsection{1. Introducción}
\begin{itemize}
	\item \textbf{Objetivo:} Filtrar información para sugerir ítems (productos, webs, series, canciones) que un usuario específico pueda encontrar interesantes.
	\item \textbf{El problema de la recomendación:} Predecir la preferencia o interacción (rating, clic, compra) de un usuario $u$ sobre un ítem $i$.
	\item \textbf{Ejemplo de intuición:} Si el Cliente X compra gafas hipster y un gorro, y el Cliente Y compra las mismas gafas, el sistema infiere que es probable que Y también compre el gorro basándose en el historial de X.
\end{itemize}

\subsection{2. Content-Based Recommender Systems (Filtrado basado en contenido)}
Se basan en las características (atributos) de los propios ítems y el perfil del usuario.

\begin{table}[htbp]
	\centering
	\small
	\begin{tabular}{|p{5cm}|p{5cm}|}

		\textbf{Ventajas} & \textbf{Desventajas} \\ \hline

\subsection{3. Collaborative Filtering (Filtrado colaborativo)}
Utiliza la matriz de interacciones (user-item) para encontrar patrones sin necesidad de conocer los atributos de los ítems.

\begin{itemize}
	\item \textbf{User-User:} Encuentra usuarios similares al usuario objetivo y recomienda lo que ellos han consumido.
	\item \textbf{Item-Item:} Encuentra ítems que suelen ser consumidos conjuntamente por el mismo grupo de usuarios.
	\item \textbf{Latent Factors (Factores latentes):} Técnicas como la \emph{Matrix Factorization} (SVD, ALS) que descomponen la matriz de interacción en vectores de baja dimensión (embeddings) que capturan la "esencia" latente de usuarios e ítems.
\end{itemize}

\subsection{4. Evaluación de Sistemas de Recomendación}
La métrica depende de si el problema se trata como regresión o como ranking.

\begin{enumerate}
	\item \textbf{Métricas de error (Regresión):} Usadas cuando predecimos ratings numéricos.
	\begin{itemize}
		\item MAE (Mean Absolute Error), MSE (Mean Squared Error), RMSE.
	\end{itemize}
	\item \textbf{Métricas de clasificación (Implicit feedback):} Útiles si determinamos si un ítem es relevante o no.
	\begin{itemize}
		\item \textbf{Precision@K:} Fracción de ítems relevantes dentro de los $K$ recomendados.
		\item \textbf{Recall@K:} Fracción de ítems relevantes recuperados dentro de los $K$ frente al total de relevantes.
	\end{itemize}
	\item \textbf{Métricas de Ranking (Orden):} Miden la calidad del orden en la lista.
	\begin{itemize}
		\item NDCG (Normalized Discounted Cumulative Gain), RBP (Rank Biased Precision), ERR.
	\end{itemize}
\end{enumerate}

\subsection{5. Práctica y Aplicación en Código}
\begin{lstlisting}[language=Python, caption=Carga y preparación básica para sistemas de recomendación]
	# Uso de PyTorch para modelado de embeddings (ej. Matrix Factorization)
	class RecommenderNet(nn.Module):
	def __init__(self, num_users, num_items, emb_size=50):
	super().__init__()
	self.user_emb = nn.Embedding(num_users, emb_size)
	self.item_emb = nn.Embedding(num_items, emb_size)
	
	def forward(self, user_idx, item_idx):
	return (self.user_emb(user_idx) * self.item_emb(item_idx)).sum(1)
\end{lstlisting}

\section{Autoevaluación razonada}

\subsection*{Pregunta} ¿Qué diferencia hay entre filtrado colaborativo y basado en contenido?
\textbf{Solución.} El colaborativo explota la "sabiduría de la multitud" (interacciones), mientras que el basado en contenido explota las propiedades descriptivas de los objetos.

\subsection*{Pregunta} ¿Por qué una métrica debe definirse con cuidado?
\textbf{Solución.} La optimización de una métrica (ej. precisión) puede reducir otras (ej. diversidad), por lo que debemos alinear la métrica con el objetivo de negocio (ej. retención, descubrimiento o conversión).
